# Android 기기 매트릭스 실패와 v1.3.28 대응

## 확인한 실패

2026-11-07 한국 시간 실행된 [주간 기기 매트릭스](https://github.com/DevDooly/Slivue/actions/runs/42311513779)는 `f5942d8`을 검증했다. 공개 릴리스 빌드가 실패한 것이 아니며 API 31·34·35는 통과했다.

- API 26: 정책 화면 생성 중 `No WebView installed`로 시험 프로세스가 종료됐다. 기존 순정 AOSP 이미지에 WebView 제공자가 없는데 v1.3.27의 정책 화면이 이를 전제로 삼았다.
- API 36: 9개 중 합성 답장 키보드 시험 하나가 10초 후 실패했다. 기존 로그는 열기와 닫기 중 어느 대기 단계인지 구분하지 못했다. 로컬 Google API 이미지의 성공만으로 순정 Managed Device 동작까지 보장할 수 없었다.
- 당시 워크플로에는 실패한 계측 HTML/XML·추가 출력 자료의 보존 단계가 없었다.

## 수정 내용

### WebView가 없어도 정책 전문 읽기

- 제공자 확인·생성·설정·로컬 HTML 로드에 실패하면 네이티브 스크롤 읽기 화면으로 전환한다.
- 동일한 로컬 한국어·영어 정책을 사용하고 두 언어 전환·텍스트 선택·뒤로가기를 제공한다.
- 기본 WebView의 JavaScript·네트워크·파일/콘텐츠 접근 차단은 유지한다. 대체 화면에서는 HTML 링크를 클릭 가능한 외부 동작으로 바꾸지 않는다.
- 제공자 없음과 생성 실패를 내부 테스트 팩터리로 검증한다. 외부 Intent로 시험 모드를 켜거나 동의·권한을 우회하는 기능은 추가하지 않는다.
- API 26 CI의 기존 순정 이미지는 유지해 WebView 없는 실제 경로도 계속 시험한다.

### 실제 키보드 시험의 준비 조건과 진단

- 기본 입력기가 실제 선택·활성 상태인지 먼저 확인한다.
- 시험 동안 하드웨어 키보드 사용 중 소프트키보드 표시 설정을 적용하고 원래 값으로 복원한다. Android 16·입력기별로 이 설정 효과는 다를 수 있으므로 설정값만으로 성공 처리하지 않는다.
- 패널의 실제 창 포커스 준비, 답장 입력 포커스, 실제 IME 창 표시, 시스템 뒤로가기 후 IME 닫기를 별도 조건으로 검증한다.
- 입력 내용 확인과 패널 생존 검증을 보존하며 각 대기의 10초 제한을 늘리거나 실패 검증을 생략하지 않는다.
- 실패 메시지·추가 출력에 해당 단계와 IME·포커스·Insets 상태를 남긴다. 알림 본문·답장 입력·창 제목은 이 진단에 쓰지 않는다.
- 패널 투명 Activity·미디어/PiP 제어 등 제품 동작은 이 시험 보완을 위해 변경하지 않는다.

### CI 증거 보존

- 성공·실패와 무관하게 계측 HTML/XML·UTP·추가 출력과 가능한 에뮬레이터 진단을 7일 보관한다.
- API 26 부팅 뒤 WebView·입력기 상태를 기록한다. 종료된 Managed Device에 ADB가 없어도 기존 시험 보고서는 업로드한다.
- 수집 스크립트는 GitHub Actions CI의 `emulator-*`만 대상으로 한다. 개인 기기, 원문 알림 덤프, 키·환경 변수·SDK 캐시는 수집하지 않는다.
- 읽기 명령마다 10초 상한을 두고, 시험 제한 확대·자동 재시도·검증 생략으로 실패를 숨기지 않는다.

## 검증 기록

로컬 표준 명령 `testDebugUnitTest compileDebugKotlin lintRelease assembleRelease`와 Play AAB·직접 배포 축소 APK·기기 시험 APK 생성이 성공했다.

- 단위 시험: 직접 배포 310개 + Play 293개 = **603개 통과**, 실패·오류·건너뜀 0.
- 소개·산출물 검사 도구: **37개 통과**.
- Google API 가상 기기: API 26·36에서 각각 **10개 계측 통과**. 네이티브 읽기 강제 경로와 실제 키보드·입력·뒤로가기·권한 철회 시험을 포함한다.
- 린트: 오류 0, 직접 배포 경고 70개 / Play 경고 125개. 경고 전체 해소를 의미하지 않는다.
- CI 수집 스크립트: Bash 구문 및 CI 밖 실행 차단을 확인했다.

이 로컬 성공을 순정 CI 이미지의 성공으로 대신하지 않는다. 원격에서는 수정 커밋을 `main`에 푸시한 뒤 `Android Device Matrix`를 수동 실행하고 API 26·31·34·35·36 전체 결과를 확인한다. 실패한 예전 커밋을 그대로 재실행하는 것과 구분한다. 원격 결과는 [기기 매트릭스 실행 목록](https://github.com/DevDooly/Slivue/actions/workflows/android-device-matrix.yml)에서 해당 수정 커밋과 함께 확인한다.

기기 매트릭스가 통과한 수정 커밋에 `v1.3.28` 태그를 붙인다. Play의 서명·공개 개인정보처리방침·계정 확인 등 [제출 조건](GOOGLE_PLAY_SUBMISSION_CHECKLIST.md)은 이번 CI 수정으로 완료되지 않는다.
