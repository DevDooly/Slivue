# Slivue v1.3.25

멜론·지니 음악 재생 중 Slivue를 열면 음악이 일시정지되던 문제에 대응했습니다.

## 변경 사항

- [멜론](https://play.google.com/store/apps/details?id=com.iloen.melon)과 [지니뮤직](https://play.google.com/store/apps/details?id=com.ktmusic.geniemusic)을 영상 사전 일시정지 대상에서 제외합니다.
- `패널 열기 전 영상 일시 정지` 설정을 켜 둬도 두 음악 앱에는 Slivue가 일시정지를 요청하지 않습니다. 기존 설정을 끄거나 바로가기를 다시 등록할 필요가 없습니다.
- YouTube 등 다른 PiP 영상 앱의 사전 일시정지와 기존 음악 앱 제외 정책은 유지합니다.
- 음악을 다시 재생하는 명령이나 전역 미디어키를 보내지 않습니다. 앱 식별자·저장 데이터·서명 계보를 유지하며 빌드 번호는 155입니다.

음악 보호를 우선해 멜론·지니 앱 전체를 제외하므로, 두 앱 내부의 뮤직비디오도 자동 일시정지하지 않습니다.

## 검증 범위

- 멜론·지니가 PiP를 지원한다고 가정한 회귀 검사, 기존 음악 앱 제외 검사와 일반 PiP 영상 앱의 대상 유지 검사를 추가했습니다.
- 로컬 단위·회귀 테스트 215개가 통과했습니다. 디버그 컴파일, Lint(오류 0개), 일반·축소 릴리스 빌드와 기존 서명 계보 검증을 완료했습니다.
- 실제 멜론·지니 계정으로 음악을 재생하는 실기기 시험은 수행하지 않았습니다.
