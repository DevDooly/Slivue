# Slivue v1.3.26

알림 필터를 한 번만 펼쳐 바로 관리할 수 있게 하고, 설정 화면 전체를 정리했습니다.

## 변경 사항

- `알림 필터 → 알림 필터링 & 제외 관리`의 중복 펼침을 없앴습니다. 이제 `알림 필터`를 한 번 누르면 차단 키워드와 앱별 수신 설정이 바로 나타납니다.
- 키워드 입력을 앱 목록보다 위에 배치했습니다. 공백만 입력하면 추가 버튼이 비활성화되고, 입력 앞뒤 공백은 정리합니다. 입력 중인 내용과 펼침 상태는 화면 복원 시 유지합니다.
- 설정을 `알림`, `화면 꾸미기`, `동작 및 연동`, `앱 정보`로 묶었습니다. 핸들·패널 크기와 라이팅 상태는 메뉴를 펼치지 않아도 확인할 수 있습니다.
- 글꼴도 한 번만 펼쳐 선택합니다. 패널 동작, 제스처·외부 앱 연동, 고급 진단은 별도 메뉴로 분리했습니다.
- 스위치 옆 제목·설명을 눌러도 전환됩니다. 키워드 삭제·색상 선택 등 작은 조작 영역을 넓히고, 본문 대비·간격·줄바꿈과 접근성 설명을 개선했습니다.
- 큰 시스템 글씨에서 상단 로고·버전이 잘리지 않도록 높이가 내용에 맞게 늘어납니다. 한국어와 영어를 함께 반영했습니다.

기존 설정값·알림 처리·앱 식별자·서명 계보를 유지합니다. 멜론·지니 음악 보호와 PiP 대응 바로가기 동작도 그대로입니다. 빌드 번호는 156입니다.

## 검증 범위

- 실제 설정 화면의 한 번 펼침, 키워드 추가·삭제, 글꼴 선택의 저장소 전달을 회귀 검사합니다.
- 앱별 제외 전환, 공백 입력, 미완성 입력·펼침 상태 복원, 큰 글씨에서 긴 키워드의 삭제 조작을 검사합니다.
- 로컬 단위·회귀 222개(추가 7개), 디버그 컴파일, Lint(오류 0개·기존 경고 68개), 일반·축소 릴리스 빌드를 검증했습니다.
- 일반·축소 APK의 기존 서명 계보를 검증했고, Android 16 에뮬레이터에서 기존 설치 위 업데이트와 축소 빌드의 설정 화면 실행도 확인했습니다.
- Android 16 전용 에뮬레이터에서 한국어 메뉴와 키워드 입력·추가·삭제, 영어·320dp 폭·글씨 2배 환경의 상단·입력 라벨·줄바꿈을 확인했습니다. 실제 삼성 기기에서 이번 설정 화면을 별도로 시험하지는 않았습니다.
