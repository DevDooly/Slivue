# Slivue v1.3.28 — 정책 화면 호환성과 기기 회귀 검증 보완

- Android System WebView가 없거나 초기화에 실패해도 개인정보 안내를 네이티브 읽기 화면으로 표시합니다. 한국어·영어 전환, 전문 스크롤과 뒤로가기를 지원합니다.
- 기본 WebView의 네트워크·JavaScript·파일/콘텐츠 접근 차단과 기존 동의·권한·중지 조건을 유지합니다. 새 권한이나 네트워크 전송은 추가하지 않습니다.
- 가상 기기의 답장 키보드 시험에서 창 포커스·입력기 준비를 확인하고 열기·닫기 실패를 구분하도록 보완했습니다. 실제 키보드 표시·입력·뒤로가기 후 패널 유지 검증은 계속 수행합니다.
- 기기 매트릭스에 계측 보고서와 제한된 시험 환경 진단 자료 보존을 추가했습니다.

기존 GitHub판의 설치 식별자·데이터 키·서명 계보는 유지합니다. Play판은 별도 `com.devdooly.slivue`이며 여전히 제출 준비 단계입니다. 이번 GitHub 릴리스는 Play 게시나 심사 승인을 의미하지 않습니다.

상세 원인·검증 범위는 [기기 매트릭스 대응 기록](https://github.com/DevDooly/Slivue/blob/v1.3.28/docs/ANDROID_DEVICE_MATRIX_V1_3_28.md)을 참고하세요.
