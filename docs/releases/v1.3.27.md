# Slivue v1.3.27 — Play 빌드 분리와 알림 접근 제어

## 기존 GitHub판을 업데이트하는 분께

설치 식별자와 기존 설정·서명 계보는 유지합니다. 이번 버전은 **알림 내용을 처리하기 전에 앱 내부 안내에 명시적으로 동의**해야 합니다. 이전에 시스템 알림 접근을 허용했더라도 앱을 열어 안내를 확인해 주세요. 거부하거나 나중에 선택하면 알림 내용을 처리하지 않습니다.

- 개인정보 처리 안내를 한국어·영어로 읽을 수 있습니다.
- 설정과 실행 알림에 **전체 서비스 중지**를 추가했습니다. 중지하면 알림 처리·오버레이를 멈추고 Slivue 메모리 이력을 비웁니다.
- 동의 철회, Android 권한 철회, 일시 중지 상태를 리스너·답장·미디어 제어·외부 명령·부팅 실행에 반영합니다.
- 서비스 상태 알림을 확인 가능한 LOW 중요도로 조정하고 알림 보내기 권한을 별도 선택 항목으로 안내합니다.
- 다른 앱의 원본 알림을 지우지 않고 Slivue 이력만 비우는 기능과 앱 데이터 관리 진입을 제공합니다.
- compile/target SDK 36 및 새 도구체인에 대응합니다. 최소 Android 8.0 지원은 유지합니다.

## Google Play판은 아직 출시 전입니다

Play판은 사용자 선택에 따라 **`com.devdooly.slivue`**라는 새 앱으로 분리합니다. 기존 `com.devdooly.notificationedge` GitHub판을 덮어쓰지 않으며, 설정·권한·이력을 자동으로 이전하지 않습니다.

Play 전용 AAB는 자체 APK 업데이터·설치 권한·인터넷 권한·온라인 폰트 제공자·진단 원문 내보내기를 제외합니다. 시스템·사용자 폰트는 유지하고 클라우드/D2D 백업을 제외합니다. 한·영 정책 초안과 스토어 소개·기능 그래픽을 준비했습니다.

**공개 운영 이름·문의 이메일·정책 URL·최종 시행일·업로드 키·Play Console 작업은 확정 전입니다.** 이 GitHub 릴리스는 Play 게시·정책 승인·최종 제출 준비 완료를 의미하지 않습니다. 미서명 AAB 후보를 업로드용 파일로 사용하지 마세요. 최종 제출 후보는 별도 준비 게이트와 실제 서명 검사를 통과해야 합니다.

단위 테스트 575개, 검사 도구 테스트 37개, Android 8·16의 계측 각 9개가 통과했습니다. 기존 공개 APK의 두 OS 업데이트와 서명 계보도 확인했습니다. 이는 삼성 실기기·16KB 런타임·Play 심사 결과를 의미하지 않습니다.

상세 상태와 남은 순서는 [Play 제출 점검표](https://github.com/DevDooly/Slivue/blob/v1.3.27/docs/GOOGLE_PLAY_SUBMISSION_CHECKLIST.md)와 [준비 검증 보고서](https://github.com/DevDooly/Slivue/blob/v1.3.27/docs/GOOGLE_PLAY_PREPARATION_REPORT.md)에서 확인하세요.
