# Slivue 배포 국가·지원 언어·대상 연령 준비

기준일: 2026-11-23. 이 문서는 사용자 결정과 Console 입력 준비를 기록하며, 실제 국가 선택·등급 설문·심사 제출 완료를 뜻하지 않는다.

## 1. 사용자가 결정한 범위

- 한국은 배포 대상에 포함한다. 추가 요건에 문제가 없다면 여러 나라에도 배포하는 방향을 허용했다.
- 어린이용으로 기획한 앱이 아니며, 실제 대상은 **13~15세·16~17세·18세 이상인 청소년과 성인**으로 사용자가 선택했다.
- 위 선택은 대상 사용자에 관한 결정이다. 국가별 콘텐츠 등급이나 모든 나라에서의 아동 해당 여부를 결정하지 않는다.

## 2. 언어와 국가는 별도 설정

| 항목 | 결정하는 것 | Slivue 준비 기준 |
| --- | --- | --- |
| 배포 국가·지역 | 어느 Play 계정 국가의 사용자가 설치할 수 있는지 | 한국 포함. 해외 후보는 아래 표를 기준으로 검토 |
| 스토어 소개 언어 | 앱 이름·설명·이미지의 표시 언어 | 영어 `en-US` 기본 소개와 한국어 `ko-KR` 번역으로 등록하는 계획 |
| 앱 화면 언어 | 설치 후 앱이 표시하는 언어 | 기본 리소스가 영어이며 한국어 번역을 제공. 국가가 아닌 Android 언어 설정에 따라 선택 |
| 공개 정책·README 언어 | 웹 안내 문서를 읽는 언어 | 한·영 문서를 제공. 문서 존재만으로 Play 번역이나 배포 국가가 자동 등록되지 않음 |

Play의 배포 대상은 현재 여행 중인 위치가 아니라 사용자의 **Google Play 계정 국가**를 기준으로 한다. 국가 설정은 같은 앱의 배포 트랙에서 관리하므로 해외 국가마다 별도 앱·설치 식별자를 만들지 않는 구조로 준비한다. `com.devdooly.slivue`와 같은 Play AAB를 사용한다. [국가별 배포 공식 안내](https://support.google.com/googleplay/android-developer/answer/7550024?hl=en)

스토어 번역은 사용자의 언어 선호에 맞춰 표시된다. 한국에서 영어를 사용하는 사람에게도 영문 소개가 표시될 수 있으며, 해외에 있다는 이유만으로 모두 영어가 표시되는 것은 아니다. 등록하지 않은 언어에서는 기본 언어나 Google의 자동 번역이 제공될 수 있다. 영어를 기본 소개로 두는 것은 다국가 안내를 위한 준비안이며 아직 Console에 적용한 설정이 아니다. [번역·현지화 공식 안내](https://support.google.com/googleplay/android-developer/answer/9844778?hl=en)

앱의 영어 기본 리소스는 `app/src/main/res/values`, 한국어는 `values-ko`이며 `xml/locales_config.xml`에 두 언어를 선언했다. Play 번역과 앱 문자열 번역을 서로 대신하는 것으로 취급하지 않는다.

## 3. 초기 해외 배포 검토안

현재 한·영 지원을 활용해 다음 여섯 국가를 초기 범위로 검토한다. **한국과 조건부 해외 확대는 사용자 결정이고, 아래 해외 개별 국가 목록은 작업 중 수립한 검토안**이다. 국가별 요건과 지원 가능 범위를 확인한 뒤 실제 Console 목록에 적용한다.

| 국가 | 준비 상태 |
| --- | --- |
| 대한민국 | 사용자 지정 배포 국가. 한국어·영어 안내 준비 |
| 미국 | 초기 해외 검토 후보. 영어 안내 준비 |
| 캐나다 | 초기 해외 검토 후보. 영어 안내와 해당 지역 요구 확인 |
| 영국 | 초기 해외 검토 후보. 영어 안내와 거래자 상태·공개 정보 요구 확인 |
| 호주 | 초기 해외 검토 후보. 영어 안내 준비 |
| 뉴질랜드 | 초기 해외 검토 후보. 영어 안내 준비 |

목록에 없는 국가를 영구 제외한 것은 아니다. Console의 추가 정보 요구·등급·정책·지원 가능 여부를 확인하며 확장한다. 영어 문서가 있다는 이유로 전 세계 요건을 충족했다고 기록하지 않는다. [국가·지역별 추가 요건](https://support.google.com/googleplay/android-developer/answer/6223646?hl=en)

## 4. 연령과 콘텐츠 등급

Console의 대상 연령 준비값은 **13~15세·16~17세·18세 이상**이다. 13세 미만을 주 대상으로 하는 어린이 앱으로 기획하지 않았다. 이 결정만으로 성인 전용 제한을 켜거나 앱에 새 나이 입력 기능을 넣지 않는다.

13~15세와 16~17세도 일부 지역에서는 아동에 포함될 수 있으므로, 배포 국가의 실제 요구를 확인한다. “어린이용 아님”을 모든 아동 관련 요건의 면제로 해석하지 않는다. [대상 사용자·연령 공식 안내](https://support.google.com/googleplay/android-developer/answer/9867159?hl=en)

IARC 콘텐츠 등급은 실제 기능과 콘텐츠에 대한 별도 설문으로 정해진다. 대상 연령 13세 이상이라는 이유로 한국의 특정 연령 등급이나 해외 등급을 미리 선택하지 않는다. [콘텐츠 등급 공식 안내](https://support.google.com/googleplay/android-developer/answer/9859655?hl=en)

## 5. 실제 등록에서 확인할 항목

1. 같은 Play 앱에서 기본 영어 소개·한국어 번역·언어별 그래픽을 등록하고 표시 결과를 확인한다.
2. 국가·지역별 안내와 실제 지원 범위를 확인한 뒤 프로덕션 및 공개·비공개 테스트 트랙의 국가를 선택한다. 내부 테스트는 별도 국가 동작을 사용하므로 최종 프로덕션 공개와 구분한다.
3. 대상 연령 세 구간을 실제 선택하고 IARC 질문에는 기능에 맞게 응답한다.
4. 거래자·비거래자 상태와 필요한 연락처 공개·약관 항목을 Console에서 확인한다. 개인 계정이나 현재 광고 없음만으로 비거래자라고 확정하지 않는다.
5. 사용자가 채택한 최종 정책 전문·시행일 **2026-11-23**을 적용해 서명 AAB·실제 설치 검증을 진행한다. 배포 국가나 실제 처리 방식이 달라지면 해당 요구와 정책·신고를 재검토한다.

2026-11-23 확인한 공식 문서는 신규 계정에 거래자 상태의 즉시 선언을 요구하며, 기존 활성 계정에는 **2027-02-01**까지 선언하도록 안내한다. 이 요구는 배포 국가와 무관하므로 EEA·영국을 제외하면 선언 자체가 불필요하다고 안내하지 않는다. EEA·영국 배포와 거래자 상태에 따른 세부 공개 항목은 소유자가 실제 계정과 활동을 기준으로 확인한다. 이 문서는 상태를 대신 선언하거나 개인정보를 수집하지 않는다. [거래자 상태 선언 공식 안내](https://support.google.com/googleplay/android-developer/answer/17594752?hl=en)

실제 등록 순서는 [Console 입력 가이드](PLAY_CONSOLE_ENTRY_GUIDE.md), 전체 미완료 항목은 [제출 점검표](GOOGLE_PLAY_SUBMISSION_CHECKLIST.md)를 따른다.
