# Slivue Play 실제 등록 진행 기록 — 2026-11-27

## 현재 결과

DevDooly의 Play Console에 무료 앱 **Slivue**, 패키지 **`com.devdooly.slivue`**를 생성했다. 사용자는 생성 직전에 개발자 프로그램 정책 준수·Play 앱 서명 서비스 약관·미국 수출 규정 준수의 세 선언에 명시적으로 동의했다. 계정의 전화번호 두 항목도 실제 화면에서 인증 완료를 확인했다.

**내부 테스트 1.3.29(159)는 출시·활성화했다. 공개 프로덕션 출시와 심사 제출은 아직 완료되지 않았다.** 내부 테스트 화면의 `검토되지 않음` 및 임시 이름 `com.devdooly.slivue (unreviewed)`을 심사 승인으로 해석하지 않는다.

- 한국어·영어 출시 노트를 등록했다.

- [내부 테스트 참여 링크](https://play.google.com/apps/internaltest/4700742077868586308). 이 링크만으로 임의 사용자가 테스트 대상에 추가되지는 않는다.
- 업로드에는 차단 오류가 없었다. 난독화 매핑·네이티브 디버그 심볼 미제공 경고가 있었으며, 파일을 임의 생성해 해결한 것처럼 처리하지 않았다. 최초의 테스터 미지정 경고는 목록을 적용해 트랙을 활성화했다.
- Google의 기본 자동 보호 설정을 유지했다. 업로드 개인키·암호 파일은 제출하거나 공개하지 않았다.

## 한·영 스토어 초안

기본 언어는 영어(미국)이며 한국어를 추가했다. 기존 `docs/google-play/listings/`의 언어별 이름·짧은 설명·상세 설명 전문을 입력하고 **임시보관함 저장 성공**을 확인했다.

- 영어: `Slivue - Edge Notifications`.
- 한국어: `Slivue - 엣지 알림 패널`.
- 기존 512×512 Slivue 아이콘을 업로드했다.
- 영어에는 `feature-en.png`, 한국어에는 `feature-ko.png` 대표 이미지를 적용했다.
- 최종 Play 버전의 휴대전화 스크린샷 최소 2장이 없어 등록정보는 아직 초안이다. 예전 직접 배포판이나 준비용 버전 화면을 최신 Play 화면인 것처럼 제출하지 않았다.

## 실제 남은 조건과 재개 순서

1. **소유자 답변:** IARC 콘텐츠 등급 설문은 별도 [서비스 약관](https://web.iarcservices.com/terms) 동의 안내가 있어 작성·제출 동의를 요청했다. 앱 생성 때 승인한 세 선언과 별개다. 등급을 추측하거나 설문 완료로 표시하지 않았다.
2. **소유자 답변:** 개발자 계정은 이미 판매자로 선언된 상태다. Slivue가 이를 그대로 상속할지 확인을 요청했고, 임의로 비판매자로 바꾸거나 저장하지 않았다. 선택사항인 앱 서비스 약관 URL도 만들거나 꾸며 넣지 않았다.
3. **실제 Play 설치·검증:** 확인 당시 `adb devices -l`에 연결 기기가 없었다. 승인된 테스트 계정으로 참여·설치한 뒤 권한 고지/거부/허용/철회/중지/재개·알림·답장·폰트·외부 링크·백업/삭제와 전송을 확인한다. 과거 로컬 빌드·CI 성공을 Play 설치 검증으로 대신하지 않는다.
4. **제출 자료:** 최종 Play 화면의 스크린샷 최소 2장과 실제 포그라운드 서비스 시연 영상을 준비한다. Console의 `FOREGROUND_SERVICE_SPECIAL_USE` 신고에는 기타 작업 설명과 영상 링크가 필수다. 영상이 없어 신고를 저장·제출하지 않았다. 녹화 절차는 [기존 점검표](GOOGLE_PLAY_SUBMISSION_CHECKLIST.md)를 따른다.
5. **데이터 보안:** 최종 설치물의 실제 처리·전송·SDK·사용자 주도 원래 앱 답장 전달과 정책을 대조한 뒤 신고한다. 현재 양식은 미완료이며 `수집·공유 없음`을 일괄 선택하지 않았다. [Google 공식 정의](https://support.google.com/googleplay/android-developer/answer/10787469?hl=ko)는 기기 내 처리와 사용자 주도 공유 예외를 구분한다.
6. **국가·심사:** 한국 포함 해외 후보별 요구와 실제 배포 국가를 확정한다. 이번에 국가 선택은 수행하지 않았다. 등록정보·필수 선언을 모두 마친 뒤 검토를 위해 전송한다. 게시 개요의 **검토를 위해 앱 전송** 버튼은 필수 단계 미완료로 비활성이었다.
7. **비공개 테스트:** 대시보드는 **최소 12명이 연속 14일 이상 비공개 테스트 참여**를 요구한다. 실제 비공개 테스트 참여자는 현재 0명이며, 프로덕션 신청 버튼은 비활성이다. 내부 테스트의 소유자 목록을 12명 요건이나 14일 시작으로 계산하지 않는다.
8. 위 조건 충족 후 실제 피드백·수정·재검증 결과로 프로덕션 접근을 신청하고 승인 후 출시를 진행한다.

## 기록·빌드 경계

브라우저의 저장·출시 성공 상태와 비활성 심사 버튼을 직접 확인했으며 증거 이미지는 개인정보가 포함될 수 있어 Git에서 제외된 `app/build/`에 보관했다. 이 문서에는 전화번호·인증코드·비공개 계정 식별자를 기록하지 않는다.

이번에는 앱 소스나 빌드 입력을 변경하지 않았다. 기존에 통과한 단위 테스트 603개·컴파일·린트·조립·AAB 전체 서명 검사와 오늘의 Console 작업은 서로 다른 증거다. 기존 직접 배포판 v1.3.29 및 태그는 유지한다.

이전 SDK 복구·정책 확정·로컬 서명 검증 내역은 [2026-11-23 기록](PLAY_REGISTRATION_PROGRESS_2026_11_23.md), 현재 미완료 기술 검증의 상세 기준은 [제출 점검표](GOOGLE_PLAY_SUBMISSION_CHECKLIST.md)를 참고한다.
