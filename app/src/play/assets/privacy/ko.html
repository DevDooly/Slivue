Slivue 개인정보처리방침

공개·제출용 최종 방침이 아닙니다.

운영 주체의 공개 이름과 개인정보 문의 이메일, 정책의 공개 웹 주소가 아직 확정되지 않았습니다. 아래 내용은 첫 Google Play 버전의 설계를 설명하는 준비본이며, 최종 앱의 처리·권한·네트워크·백업 검증과 운영 정보 확정 후 다시 승인해야 합니다. 이 상태로 Google Play에 제출하거나 이미 시행 중인 방침처럼 게시하지 않습니다.

1. 적용 대상과 운영 정보

2. 처리할 정보와 목적

  • 알림: 사용자가 알림 접근 고지에 동의하고 Android의 알림 접근을 허용한 경우, 다른 앱의 알림 제목·본문·발신자 표시·앱 식별자와 이름·수신 시각·대화 메시지·답장 동작을 읽습니다. 최근 알림 표시, 대화별 정리, 앱·키워드 필터, 빠른 답장과 선택한 엣지 라이팅을 위해 사용합니다.
  • 빠른 답장: 사용자가 직접 입력한 답장을 Android 알림의 답장 동작으로 원래 메시지 앱에 전달합니다. 이후 상대방에게 보내는 처리와 보관은 해당 앱의 정책을 따릅니다.
  • 설정: 핸들·패널·라이팅 모양, 선택한 글꼴, 발견 앱과 제외 앱 목록, 차단 키워드, 사용자가 선택한 실행·제스처 옵션을 앱 내부 저장소에 보관합니다.
  • 사용자 폰트: 사용자가 시스템 파일 선택기로 지정한 폰트 파일과 파일명을 앱 내부 저장소로 복사해 글꼴 표시에 사용합니다. Play판은 시스템 글꼴과 직접 불러온 파일을 사용하도록 준비하며 Google Fonts 다운로드 제공자를 포함하지 않는 방향입니다.
  • 동의·중지 상태: 고지 버전·동의 시각과 처리 중지 상태를 기기에 기록합니다. 동의 기록을 다른 기기의 권한 허용으로 재사용하지 않도록 Android 백업 대상이 아닌 위치에 보관합니다.
  • 선택적 영상 일시정지: 사용자가 해당 옵션을 켜고 패널을 열면 활성 미디어 세션의 앱과 재생 상태를 확인해 지원되는 영상 세션에 일시정지 명령을 보낼 수 있습니다. 녹음·화면 녹화 기능은 아닙니다.

알림 접근과 서비스가 활성화되어 있고 전체 처리가 중지되지 않은 동안에는 설정 화면을 보고 있지 않을 때도 알림을 처리할 수 있습니다. 운영체제나 원래 앱이 숨긴 민감한 알림을 복원하거나 보호 기능을 우회하지 않습니다.

3. 기기 밖 전달과 외부 서비스

첫 Play판은 알림 표시·필터링을 기기에서 처리하고 Slivue 개발자 서버로 알림·답장을 업로드하지 않는 구성을 목표로 합니다. 자체 GitHub APK 업데이트, 다운로드 글꼴, 알림 원문 진단 내보내기, 광고·분석·로그인 SDK와 앱 자체 인터넷 권한은 Play 산출물에서 제외하는 방향입니다. 최종 산출물·전이 의존성·실제 통신 검증이 끝나기 전에는 이를 검증 완료된 “수집·공유 없음” 선언으로 해석하지 않습니다.

사용자가 빠른 답장을 보내거나 원래 알림 앱을 열면 Android를 통해 해당 앱에 동작이 전달됩니다. 공개 정책이나 스토어 페이지를 외부 브라우저·스토어로 열면 해당 외부 서비스가 자신의 정책에 따라 접속 정보를 처리할 수 있습니다. Slivue가 알림 원문을 그 링크에 붙여 전달하는 방식은 사용하지 않습니다.

4. 저장 기간과 삭제

  • 알림 이력은 앱 메모리에 최대 150개 알림, 알림당 최대 50개 메시지로 제한합니다. 새 알림에 따라 오래된 내용은 교체될 수 있습니다.
  • 시스템 알림창에서 알림을 지우는 것과 Slivue의 이력을 지우는 것은 다를 수 있습니다. Slivue의 이력 지우기, 전체 처리 중지, 동의 철회 또는 알림 접근 철회 시 메모리 이력을 비우는 흐름으로 준비합니다.
  • 프로세스가 종료되면 메모리 이력은 사라집니다. 이후 다시 동의·권한 조건을 만족하면 Android에 남아 있는 활성 알림을 다시 읽을 수 있으므로 영구 삭제와 같지는 않습니다.
  • 발견 앱 목록·차단어·제외 설정은 사용자가 앱에서 삭제·변경하거나 Android 설정에서 앱 데이터를 지우기 전까지 보관할 수 있습니다. 전체 처리를 멈추거나 알림 이력을 비워도 모양과 필터 설정은 별도로 남을 수 있습니다.
  • 직접 불러온 폰트는 앱의 삭제 기능 또는 Android의 앱 데이터 삭제·앱 제거로 삭제할 수 있습니다. 원래 선택한 파일의 원본은 Slivue 내부 복사본과 별개입니다.

5. 백업과 기기 이전

Play판은 앱의 클라우드 백업과 기기 간 데이터 이전 대상에서 내부 설정·파일을 제외하는 규칙으로 준비합니다. 동의 기록은 별도로 백업되지 않는 위치에 보관합니다. 다만 제조사의 이전 도구와 Android 버전별 실제 동작은 최종 빌드로 확인해야 하며, 어떤 환경에서도 데이터 이전이 절대 일어나지 않는다고 보장하지 않습니다. 직접 배포판의 기존 설정 백업 정책과는 다릅니다.

6. 권한과 사용자의 선택

  • 알림 접근: 별도의 앱 내부 고지와 동의 후 Android 설정에서 사용자가 허용합니다. 거부해도 설정과 방침은 읽을 수 있지만 알림 패널의 핵심 기능은 제한됩니다.
  • 다른 앱 위에 표시: 다른 앱을 쓰는 동안 핸들과 라이팅을 표시합니다. Android 설정에서 언제든 해제할 수 있습니다.
  • 알림 보내기: 지원되는 Android 버전에서 실행 중인 서비스의 상태와 중지 동작을 알립니다. 다른 앱의 알림을 읽는 권한과 별개입니다.
  • 전체 처리 중지·재개: Slivue 설정 또는 서비스 알림에서 전체 처리를 중지하도록 준비합니다. 재개하려면 현재 동의와 실제 시스템 권한이 필요합니다.
  • 동의 철회: 앱에서 동의를 철회하거나 Android 설정의 알림 접근을 해제할 수 있습니다. 철회 후 새 알림 처리를 멈추며 다시 사용하려면 고지와 권한 조건을 충족해야 합니다.
  • 배터리 최적화: 백그라운드 표시가 제한되는 기기에서 확인할 선택 사항입니다. 배터리 보호를 강제로 해제하지 않습니다.

접근성 서비스, SMS·통화기록, 마이크, 카메라, 위치, 전체 저장소 접근을 알림 표시를 위한 권한으로 추가하지 않는 방향입니다. 선택 파일은 시스템 파일 선택기로 지정합니다.

7. 보안·아동·정책 변경

기기 내부 저장소와 Android 권한 경계를 사용하고 민감한 알림 원문이 로그나 지원 자료에 남지 않도록 제한합니다. 어떤 소프트웨어도 절대적인 보안을 보장하지는 않습니다. 개인정보 문의에 실제 메시지, 인증번호나 불필요한 제3자의 정보를 첨부하지 마세요.

별도 Slivue 계정 생성 기능은 준비 범위에 없습니다. 대상 연령·배포 국가·아동 관련 정책은 운영 주체가 출시 전에 확정하고 적용 요건을 확인해야 하며, 이 초안에서 연령 등급이나 아동 대상 여부를 대신 결정하지 않습니다.

처리 목적·정보·외부 전달·광고 등 중요한 변경이 있으면 실제 기능에 맞춰 정책과 스토어 신고를 갱신하고, 필요한 경우 새 고지·동의를 받습니다. 최종 시행일과 변경 통지 방법도 정식 공개 전 확정합니다.

이 문서는 2026-10-31 작성한 출시 전 준비본입니다. 공개 운영 정보와 실제 Play 산출물 검증이 완료되기 전에는 제출용 최종 방침이 아닙니다.
