Slivue 직접 배포판 개인정보 처리 안내

2026-10-31 기준 GitHub 직접 배포판(com.devdooly.notificationedge)의 구현 설명입니다. 별도 Google Play판의 정책이 아니며, 운영 연락처와 공개 개인정보처리방침 확정은 별도 준비 중입니다.

읽는 정보와 사용 목적

명시적 안내 동의와 Android 알림 접근 허용 후 앱 이름·발신자·제목·본문·시각·답장 동작을 읽어 엣지 패널에 표시하고 필터링합니다. 화면을 닫은 뒤에도 사용자가 서비스를 중지하기 전까지 동작할 수 있습니다. 선택 기능인 영상 일시 정지에는 활성 미디어 세션 정보가 사용됩니다.

답장과 외부 통신

빠른 답장은 원래 메시지 앱의 알림 답장 기능으로 전달되며, 이후 전송과 처리는 해당 앱의 정책을 따릅니다. Slivue 개발자 서버로 알림이나 답장을 올리는 경로는 없습니다. 선택 Google Fonts는 Google Play services 제공자를 통해 다운로드될 수 있습니다. 업데이트 확인·사용자가 선택한 APK 다운로드에는 GitHub와 허용된 HTTPS 다운로드 호스트가 사용됩니다. 상대 서버는 연결 과정에서 접속 정보를 처리할 수 있습니다.

저장과 백업

알림은 메모리에 최대 150개, 알림당 메시지는 최대 50개 보관합니다. 원래 앱에서 지운 알림도 Slivue 이력에는 남을 수 있습니다. 프로세스 종료로 메모리는 사라지며, 활성 시스템 알림은 다시 읽을 수 있습니다. 설정·발견 앱·제외 앱·차단어는 앱 저장소에, 사용자 폰트는 내부 파일로 보관합니다. Android와 제조사 백업·복원 설정에 따라 설정 또는 파일이 다른 기기로 이동할 수 있습니다. 고지 동의와 전체 중지 상태는 백업되지 않는 설치별 파일에 저장합니다.

선택적 진단

진단 모드는 기본적으로 꺼져 있고, 켠 경우 12시간 후 만료됩니다. 일부 정보만 마스킹하므로 이름이나 메시지 내용이 남을 수 있습니다. 복사·공유 전 내용을 직접 확인하세요. 자동 업로드 기능은 없습니다.

중지·철회·삭제

설정이나 실행 알림의 전체 서비스 중지는 알림 처리와 오버레이를 멈추고 Slivue 메모리 이력을 비웁니다. 동의 철회도 즉시 처리를 중지합니다. Android의 알림 접근과 다른 앱 위 표시 권한은 시스템 설정에서 별도로 해제할 수 있습니다. Slivue 알림 이력 비우기는 원래 앱의 알림을 삭제하지 않습니다. 개별 필터·폰트는 설정에서 삭제하고, 전체 저장 데이터는 Android 앱 저장공간의 데이터 삭제 또는 앱 제거로 지울 수 있습니다. 운영체제 백업은 해당 기기·계정의 백업 설정을 별도로 확인하세요.

계정·광고·문의

별도 Slivue 계정, 광고·분석 SDK, 인앱 결제는 포함하지 않습니다. 일반 기능 문의는 프로젝트 GitHub Issues로 접수할 수 있습니다. 공개 이슈에는 알림 원문·전화번호·계정 정보 등 민감한 내용을 올리지 마세요.
